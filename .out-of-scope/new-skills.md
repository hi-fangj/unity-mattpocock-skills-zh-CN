# 新 skill 提案与贡献

本 repo 不接受新 skills 的提案或贡献，包括自带现成 branch 或 fork 的提案。

## 为什么这不在范围内

这份 catalog 就是作者自己每天在用的 skills 集合，而且刻意保持很小。每个 skill 都是永久维护面：必须与其他 skills、docs pages、`ask-matt` 的 routing map 和 plugin manifest 保持同步。skills 越短越少，保持正确就越便宜。

作者对自己想法适用的规则在这里同样适用：如果这个行为能用现有 skills 组合出来，它就不会获得一个新 skill。大多数提案都是由 grilling、`to-spec`、`to-tickets`、`implement` 等组合出的某个具体 workflow，这种组合应该放进你自己的 prompts 或你自己的 skills。

非常欢迎你自己发布 skill。skills.sh 让这件事很直接，本 repo 里的任何东西都不需要知道它。

这里只针对*新* skills。既有 skill 中的具体缺陷，照常按上游仓库 `SCOPE.md` 的标准判断。
